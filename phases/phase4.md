# Phase 4 — Local Developer CLI

## Status
Planned

## Goal
Provide a local command line interface (`npx codeverse`) to analyze local repositories offline without uploading code.

## Planned Features
- `npx codeverse` local runner
- Local file system crawler
- Local server launcher for interactive UI
- Git ignore handling (`.gitignore`)
- Zero network telemetry & local privacy

## Implementation Status
Not implemented yet. Current active implementation is Phase 1.
