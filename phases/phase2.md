# Phase 2 — Advanced Graph Exploration & Navigation

## Status
Planned

## Goal
Enhance codebase graph exploration with advanced navigation, search, hierarchical directory grouping, and filtering tools.

## Planned Features
- Directory collapse and expand node groups
- Sub-graph depth traversal (highlight N-level dependencies)
- Advanced file type filters (.ts, .tsx, .js, .jsx, CSS, JSON)
- Custom layout algorithms (force-directed, radial, concentric)
- Export graph as PNG / SVG / JSON
